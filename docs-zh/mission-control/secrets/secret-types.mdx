---
title: "密钥类型"
description: "Continue Mission Control 内置了密钥管理功能。密钥是可以在配置和组织内共享的 API 密钥或端点等值。"
---

## 用户密钥

用户密钥由用户为自己定义。这意味着用户密钥仅对创建它们的用户可用。用户密钥被认为对用户来说是安全的，因此它们会与 `config.yaml` 一起发送到 IDE 扩展。

这允许直接从 IDE 扩展发出 API 请求。您可以在 [Solo](/hub/governance/pricing#solo)、[Teams](/hub/governance/pricing#teams) 和 [Enterprise](/hub/governance/pricing#enterprise) 中使用用户密钥。用户密钥可以在 Mission Control 中的 [此处](https://hub.continue.dev/settings/secrets) 管理。

## 组织密钥

组织密钥由管理员为其组织定义。组织密钥可供组织中的任何人用于该组织中的配置。组织密钥被认为不可与用户共享（例如，您是团队负责人，希望让团队成员访问模型而不传递 API 密钥）。

这就是为什么 LLM 请求通过 api.continue.dev / 本地代理进行代理，并且密钥永远不会发送到 IDE 扩展的原因。您只能在 [Teams](/hub/governance/pricing#teams) 和 [Enterprise](/hub/governance/pricing#enterprise) 上使用组织密钥。如果您是管理员，可以从组织设置页面管理组织的密钥。
