---
title: "如何编辑配置"
description: "可以使用侧边栏创建和发布配置的新版本。"
---

首先，从 Mission Control 搜索中选择一个配置，或者选择一个您已安装的配置。

编辑配置时，您可以浏览 Mission Control 并点击 "+" 将其添加到您的配置中。

对于需要 API 密钥等机密值的工具或模型，您会在其卡片上看到一个小通知，指示是否需要采取行动。


要删除配置的一部分，您可以从 yaml 中删除它。

如果您想要使用的规则、提示或工具尚不存在，您可以 [创建它](/hub/introduction#creating-components)。

编辑完成后，点击 "Publish" 发布配置的新版本。

重新加载您的终端或 IDE，以便在您的代理中使用配置的最新版本。
