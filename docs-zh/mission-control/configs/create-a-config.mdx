## 如何从头创建配置

要从头创建配置，请在顶部栏中选择“New config”。

为您的配置选择名称、slug、描述和图标。

创建配置的最简单方法是使用默认配置点击“Create config”，然后使用侧边栏添加/删除块。

或者，您可以在点击“Create config”之前直接编辑配置 YAML。请参考 [hub.continue.dev](https://hub.continue.dev) 上的配置示例，并访问 [YAML 参考](/reference#complete-yaml-config-example) 文档了解更多详情。



## 如何修改配置

您还可以通过修改现有配置来创建配置。如果您想从预配置的配置开始并进行修改，这会很有用。

点击“remix”按钮，您将被带到“Create a remix”页面。

在这里，您将能够

1. 从配置中添加或删除组件。
2. 更改名称、描述、图标等。

点击“Create config”将使此配置可供使用。
