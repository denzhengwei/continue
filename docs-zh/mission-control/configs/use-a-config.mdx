## 在Continue中使用自定义配置的步骤

一旦您在Continue Mission Control上找到想要使用的配置：

1. 点击其页面上的“Add Config”
2. 添加任何所需的输入（例如API密钥等机密）

保存后，打开Continue CLI或IDE扩展，然后

- 从Continue扩展中的**配置下拉菜单**选择配置
- 在Continue CLI中键入`/config`并选择配置
- 开始将其用于聊天模式、代理模式或其他配置的功能。
