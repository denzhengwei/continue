<Info>

  **什么是任务？**

  任务是一个工作单元，它结合了：
  - 您的指令
  - 代理的能力（模型、规则、工具、提示词）
  - 您的代码库（仓库和分支）

  任务可以手动触发、通过事件触发或按计划触发，并且可以分配给您团队中的任何人进行审查。

</Info>

## 创建和运行任务

<Steps>

  <Step title="选择代理">

    选择您要用于此任务的**代理**。

    <Tip>

      还没有代理？在设置第一个任务之前，在**[Mission Control → Agents](https://hub.continue.dev/new?type=agent)** 中创建一个。

    </Tip>

  </Step>

  <Step title="选择您的仓库">

    选择代理将工作的**仓库**和**分支**。


  </Step>

  <Step title="描述任务">

    添加您的用户输入——关于您希望代理完成的明确指令。

    **示例提示词：**

    ```text
    重构未使用的 React 组件并清理导入
    ```

    ```text
    为 /api 目录中的所有 API 端点添加错误处理
    ```

    ```text
    更新 README，添加新 CLI 工具的安装说明
    ```

  </Step>

  <Step title="运行任务">

    点击提交按钮。

    代理将：
    - 分析您的仓库和分支
    - 根据您的输入执行任务
    - 根据您的任务请求生成更改
    - 创建详细的会话日志

    <Info>

      任务执行时间因复杂性而异。您可以在收件箱中监控进度。

    </Info>

  </Step>

  <Step title="审查结果">

    每次任务运行都会创建一个具有完整可追溯性的会话。
  
    <AccordionGroup>
      <Accordion title="摘要">

        高级解释：
        - 代理做了什么
        - 为什么做出这些决定
        - 实施的关键更改

      </Accordion>

      <Accordion title="差异">

        确切的代码更改：
            - 修改的文件
            - 添加/删除的行
            - 并排比较

      </Accordion>

      <Accordion title="日志">

        完整的执行跟踪：
            - 进行的工具调用
            - 代理推理
            - 任何错误或警告

      </Accordion>

    </AccordionGroup>


    <Tip>

      接受更改前请仔细审查差异。您可以：
      - 接受所有更改
      - 请求修改
      - 拒绝并使用更新的输入重试

    </Tip>

  </Step>

</Steps>
