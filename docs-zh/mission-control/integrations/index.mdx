<Info>
集成允许Continue连接到您已经使用的工具，因此代理可以读取代码、打开拉取请求、发送消息、对现实世界的事件做出反应等等。
</Info>

Mission Control目前支持四个一流的集成：

<CardGroup cols={2}>

  <Card title="GitHub" icon="github" href="/mission-control/integrations/github">
    创建PR、访问仓库、查看差异和触发工作流所需。
  </Card>

  <Card title="Slack" icon="slack" href="/mission-control/integrations/slack-agent">
    在Slack中提及@continue以直接启动代理。
  </Card>

  <Card title="Sentry" icon="alert-triangle" href="/mission-control/integrations/sentry">
    当出现新的Sentry问题时自动触发代理。
  </Card>

  <Card title="Snyk" icon="shield-check" href="/mission-control/integrations/snyk">
    自动检测并修复安全漏洞。
  </Card>

</CardGroup>
