---
title: "创建组织"
description: "要创建组织，请点击右上角的组织选择器并选择"
---

![create an org selector](/images/hub/governance/images/org-selector-4ea627afc7c0765633780920a0fbe16e.png)

1. 选择一个名称，该名称将作为您的组织在整个Mission Control中的显示名称
2. 添加一个slug，该slug将用于您的组织URL，并作为所有组织配置slug的前缀
3. 使用图片上传器为您的组织选择一个图标
4. 最后，添加一个简介，该简介将显示在您的组织主页上

![Creating an org](/images/hub/governance/images/create-org-form-1c7655050d8f423b0ecdfbd1cc85e0af.png)

然后您将登录到您的组织并被带到组织主页

![Org home page](/images/hub/governance/images/org-home-page-4509e2ff8c4e1d6325c8f0afae3b16dd.png)
