## 概述

开源的 Continue 扩展收集并报告**匿名**使用信息，以帮助我们改进产品。这些数据使我们能够了解用户交互并有效优化用户体验。如果您不希望分享您的使用信息，可以随时选择退出遥测收集。

我们利用 [Posthog](https://posthog.com/)，一个开源的产品分析平台，来收集和存储这些数据。为了透明起见，您可以查看实现代码 [此处](https://github.com/continuedev/continue/blob/main/gui/src/hooks/CustomPostHogProvider.tsx) 或阅读我们的 [官方隐私政策](https://continue.dev/privacy)。

## 跟踪政策

开源 Continue 扩展收集的所有数据在发送到 PostHog 之前都会被匿名化并剥离个人身份信息 (PII)。我们致力于维护您数据的隐私和安全。

## 我们跟踪的内容

收集并报告以下使用信息：

- **建议交互：** 您是否接受或拒绝建议（不包括实际涉及的代码或提示词）。
- **模型和命令信息：** 使用的模型和命令的名称。
- **令牌指标：** 生成的令牌数量。
- **系统信息：** 您的操作系统 (OS) 和集成开发环境 (IDE) 的名称。
- **页面浏览量：** 一般页面浏览统计。

## 如何选择退出

### IDE 扩展

您可以通过在用户设置中关闭 "Allow Anonymous Telemetry" 来禁用匿名遥测。

#### VS Code

或者在 VS Code 中，您可以通过 VS Code 设置禁用遥测，取消勾选 "Continue: Telemetry Enabled" 框（这将覆盖设置页面的设置）。VS Code 设置可以通过 `File` > `Preferences` > `Settings` 访问（或在 Windows/Linux 上使用键盘快捷键 `ctrl` + `,`，在 macOS 上使用 `cmd` + `,`）。

### CLI

对于 `cn`（Continue CLI），在运行命令前设置环境变量 `CONTINUE_ALLOW_ANONYMOUS_TELEMETRY=0`：

```bash
export CONTINUE_ALLOW_ANONYMOUS_TELEMETRY=0
cn <your prompt>
```

或者内联运行：

```bash
CONTINUE_ALLOW_ANONYMOUS_TELEMETRY=0 cn <your prompt>
```
