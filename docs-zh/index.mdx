## Mission Control

<Note>用于管理代理、任务、工作流和集成的中央仪表板。</Note>

<CardGroup cols={2}>
  <Card title="创建任务" icon="plus" href="/mission-control/tasks">
    使用提示词、工具和规则触发您的代理来完成特定工作。

    <sub>• 手动运行或从收件箱运行</sub><br />
    <sub>• 与团队成员复用和共享</sub>

  </Card>
  <Card title="设置工作流" icon="clock" href="/mission-control/workflows">
    安排定期任务或连接 Webhook 以自动触发代理。

    <sub>• 基于 Cron 或 Webhook 的触发器</sub><br />
    <sub>• 适用于日常审计或状态检查</sub>

  </Card>
</CardGroup>

## 集成

<Note>将 Continue 连接到您现有的开发工具，为任务和工作流提供动力。</Note>

<CardGroup cols={2}>
  <Card
    title="GitHub"

    icon="slack"

  <Card
    title="Sentry"

  </Card>
  <Card
    title="Snyk"
    icon="shield-check"

  </Card>
</CardGroup>

## Continue CLI

<Note>带有 TUI 和无头模式的终端原生 AI 编码辅助工具。</Note>

<CodeGroup>

    ```bash npm
    npm install -g @continuedev/cli
    ```

    ```bash yarn
    yarn global add @continuedev/cli
    ```

    ```bash pnpm
    pnpm add -g @continuedev/cli
    ```

</CodeGroup>
