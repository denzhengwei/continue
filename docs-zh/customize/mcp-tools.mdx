模型上下文协议 (MCP) 服务器允许 Continue 通过运行 MCP 服务器连接到外部工具、系统和数据库。

这些服务器使以下功能成为可能：

- **启用与外部工具和系统的集成**
- **创建用于自定义功能的可扩展接口**
- **支持与您的开发环境的复杂交互**
- **允许合作伙伴贡献专业功能**
- **连接到数据库**，以便在开发过程中了解架构和数据模型
