- **[聊天](/customize/model-roles/chat)**: 为代码提供对话交互和详细指导
- **[编辑](/customize/model-roles/edit)**: 处理复杂的代码转换和重构任务
- **[应用](/customize/model-roles/apply)**: 以高精度执行有针对性的代码修改
- **[自动补全](/customize/model-roles/autocomplete)**: 在开发者输入时提供实时建议
- **[嵌入](/customize/model-roles/embeddings)**: 将代码转换为向量表示用于语义搜索
- **[重排序器](/customize/model-roles/reranking)**: 通过基于语义含义排序结果来提高搜索相关性

## 了解更多关于模型的信息

Continue 支持 [许多模型提供商](/customize/model-providers/top-level/openai)，包括 Anthropic、OpenAI、Gemini、Ollama、Amazon Bedrock、Azure、xAI 等。模型可以有各种角色，如 `chat`、`edit`、`apply`、`autocomplete`、`embed` 和 `rerank`。

阅读更多关于 [模型角色](/customize/model-roles)、[模型能力](/customize/deep-dives/model-capabilities) 的信息，并在 YAML 参考中查看 [`models`](/reference#models)。

### 示例模型设置说明

# 前沿模型

[Claude 4 Sonnet](https://hub.continue.dev/anthropic/claude-4-sonnet) 来自 Anthropic

1. 从 [Anthropic](https://console.anthropic.com/) 获取您的 API 密钥
2. 将 [Claude 4 Sonnet](https://hub.continue.dev/anthropic/claude-4-sonnet) 添加到 Continue Mission Control 上的配置中
3. 在 Continue Mission Control 上将 `ANTHROPIC_API_KEY` 作为 [用户密钥](https://docs.continue.dev/mission-control/secrets/secret-types#user-secrets) 添加 [此处](https://hub.continue.dev/settings/secrets)
4. 在 Continue IDE 扩展的配置选择器中点击 `Reload config`
