Continue 可以深度自定义，以适应您特定的开发工作流和偏好。本指南涵盖了您可以自定义 Continue 以增强编码体验的主要方式。

## 更改您的模型提供商

Continue 允许您选择自己喜欢的模型提供商，甚至添加多个模型提供商。这使您可以为不同的任务使用不同的模型，或者如果您对当前模型的结果不满意，可以尝试另一个模型。Continue 支持所有流行的模型提供商，包括 OpenAI、Anthropic、Microsoft/Azure、Mistral 等。如果您愿意，您甚至可以自托管自己的模型提供商。

[了解更多关于模型提供商的信息 →](/customize/model-providers/overview)

## 为特定任务选择不同的模型

Continue 的不同功能可以使用不同的模型。我们称这些为 _模型角色_。例如，您可以为聊天模式使用与自动补全不同的模型。

[了解更多关于模型角色的信息 →](/customize/model-roles)

## 创建自定义提示词

创建自定义斜杠命令和提示词模板，以简化您的工作流。

[了解更多关于提示词的信息 →](/customize/prompts)

## 配置规则

设置规则来指导 AI 响应，并确保在您的代码库中保持一致的行为。

[了解更多关于规则的信息 →](/customize/rules)

## 调用外部工具和函数

使用 [扩展中的代理模式](/ide-extensions/agent/quick-start) 为您的代理赋予工具能力，或使用 [MCP 服务器](/customize/mcp-tools) 向您的代理添加自定义工具。

[了解更多关于 MCP 工具的信息 →](/customize/mcp-tools)

## 自定义 VS Code 设置

调整 IDE 特定的设置，以优化您的 Continue 体验。

[了解更多关于设置的信息 →](/ide-extensions/settings)
