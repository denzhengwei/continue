## 如何在 Continue 中使用 AI 代码自动补全

自动补全在您输入时提供内联代码建议。要启用它，只需点击 IDE 右下角状态栏中的 "Continue" 按钮，或确保 IDE 设置中选中了 "Enable Tab Autocomplete" 选项。

### 接受完整建议

按 `Tab` 接受完整建议

### 拒绝完整建议

按 `Esc` 拒绝完整建议

### 部分接受建议

对于更精细的控制，使用 `cmd/ctrl` + `→` 逐词接受建议的部分内容。

### 强制生成建议（VS Code）

如果您想立即触发建议而不等待，或者您已取消了一个建议并想要一个新建议，您可以使用键盘快捷键 **`cmd/ctrl` + `alt` + `space`** 强制生成。
