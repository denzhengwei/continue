## 安装

使用 npm 全局安装 Continue CLI：

```bash
npm i -g @continuedev/cli
```

## 使用 Continue CLI 的两种方式

<Info>
  **快速概述**：Continue CLI 有两种工作模式 - 用于交互式对话的 TUI 模式或用于自动化命令的无头模式。
</Info>

<Tabs>
<Tab title="TUI 模式">
**交互式开发会话**

在终端中与 AI 开始对话：

```bash
cn
> @src/app.js 为这个组件生成单元测试
```

非常适合探索、调试和迭代开发。

</Tab>

<Tab title="无头模式">
**自动化和脚本编写**

返回结果的单个命令：

```bash
cn -p "为当前更改生成提交消息"
cn -p "审查最后 5 个提交中的问题"
```

非常适合 CI/CD、git 钩子和自动化工作流。

</Tab>
</Tabs>

## 设置

<Tabs>
<Tab title="cn TUI 模式">

用于交互式开发和探索：

<Steps>
<Step title="登录 Continue CLI">
```bash
cn login
```
这将打开您的浏览器，使用 Continue Mission Control 进行身份验证。
</Step>

<Step title="测试 TUI 模式">
启动交互式会话：
```bash
cn
```

尝试提出问题：

```
> 告诉我关于 CLI 的信息
```

</Step>
</Steps>
</Tab>
<Tab title="cn 无头模式">

用于自动化工作流和脚本编写：

<Steps>
<Step title="获取自动化 API 密钥">
对于自动化工作流，获取 API 密钥：
1. 访问 [Continue Mission Control API Keys](https://hub.continue.dev/settings/api-keys)
2. 点击 **"+ New API Key"**
3. 立即复制 API 密钥（您不会再次看到它！）
4. 使用您的 Continue 账户登录
</Step>

<Step title="为工作流添加密钥">
为 CLI 工作流存储安全凭据：
1. 访问 [Continue Mission Control Secrets](https://hub.continue.dev/settings/secrets)
2. 添加您的 API 密钥和敏感数据
3. 在配置中使用 `${{ secrets.SECRET_NAME }}` 引用
</Step>

<Step title="测试无头模式">
尝试自动化的无头模式：
```bash
cn -p "为当前 git 更改生成符合规范的提交消息"
```
</Step>
</Steps>
</Tab>
</Tabs>
