通过实际开发工作流获得 Continue CLI 的实践经验。

<Tabs>
  <Tab title="TUI 模式">
    TUI 模式（`cn` 命令）适用于**大型开发任务**，这些任务需要
    带有人工监督的代理工作流。非常适合复杂的重构、
    功能实现或需要监控和迭代的一次性自动化任务。
  </Tab>
  <Tab title="无头模式">
    无头模式（`-p` 标志）适用于**可靠、可重复的任务**，这些任务不再需要
    持续监督。非常适合 CI/CD 管道、git 钩子和 您已经测试和完善的自动化工作流。
  </Tab>
</Tabs>

## TUI 模式：大型开发任务

确保您已安装 [Continue CLI](/cli/install) 并位于项目目录中。

### 示例：实现新功能

```bash
# 导航到您的项目目录
cd your-awesome-project

# 启动 TUI 模式进行复杂的开发工作
cn
```

**添加身份验证的示例工作流：**

```
> 我需要为这个 Express 应用添加 JWT 身份验证。让我先向您展示当前的结构。

> @src/app.js @package.json 这是我当前的设置。您能实现带有中间件、登录/注册路由和用户模型的 JWT 身份验证吗？

> [代理分析代码库并实现身份验证系统]
> [您审查更改、测试并提供反馈]
> [代理根据您的输入迭代，直到功能完成]
```

### 示例：复杂重构

```bash
cn
```

**重构大型组件：**

```
> @src/components/Dashboard.jsx 这个组件有 800 行，做了太多事情。帮我把它拆分成更小的、可重用的组件。

> [代理分析组件结构]
> [提出组件分解策略]
> [您批准方法]
> [代理使用适当的 props 和状态管理实现重构]
> [您测试并请求调整]
```

### 何时使用 TUI 模式

✅ **需要监督的大型开发任务**  
✅ **需要多个步骤的复杂重构**  
✅ **带有未知因素的新功能实现**  
✅ **您以前从未做过的一次性自动化任务**  
✅ **需要探索的复杂问题调试**

## 无头模式：自动化工作流

一旦您在 TUI 模式中完善了工作流，就可以将其转换为持续 AI 进行自动化。

### 示例：从 REPL → 持续 AI

**步骤 1：在 TUI 模式中开发**

```bash
cn
> @package.json @CHANGELOG.md 为版本 2.1.0 生成发布说明
> [测试并完善提示词，直到它完美工作]
```

**步骤 2：转换为持续 AI**

```bash
# 现在在自动化中使用完善的工作流
cn -p "根据 package.json 和最近的提交为当前版本生成发布说明"
```

### 常见的持续 AI 工作流

```bash
# Git 自动化
cn -p "为暂存更改生成符合约定的提交消息"
cn -p "审查最后 3 个提交，查找潜在问题"

# 代码质量
cn -p "修复 src/ 目录中的所有 TypeScript 错误"
cn -p "更新过时的依赖项并修复破坏性更改"

# 文档
cn -p "@README.md 根据最近的更改更新文档"
cn -p "从 JSDoc 注释生成 API 文档"

# CI/CD 集成
cn -p "分析测试失败并创建带有发现结果的 GitHub 问题"
cn -p "更新版本号并创建发布分支"
```

### 何时使用无头模式

✅ **您已经在 TUI 模式中测试过的可靠工作流**  
✅ **不再需要监督的重复性任务**  
✅ **管道中的 CI/CD 自动化**  
✅ **用于自动检查的 Git 钩子**  
✅ **无人值守运行的计划任务**

<Info>
  **模式之间的工具权限差异**

需要用户确认（"ask" 权限）的工具，如 `writeFile` 和 `runTerminalCommand`：

- **在 TUI 模式中可用** - AI 可以在您的批准下使用它们
- **在无头模式中排除** - AI 无法看到或调用它们

这可以防止 AI 在自动化环境中尝试需要用户交互的操作。如果您的工作流需要修改文件或运行命令的工具，请选择 TUI 模式。

</Info>

### 可用的斜杠命令

CLI 中可用的常见斜杠命令：

- `/clear` - 清除聊天历史
- `/compact` - 将聊天历史汇总为紧凑形式
- `/config` - 切换配置或组织
- `/exit` - 退出聊天
- `/fork` - 从当前历史开始一个分叉的聊天会话
- `/help` - 显示帮助消息
- `/info` - 显示会话信息
- `/init` - 创建 AGENTS.md 文件
- `/login` - 使用您的账户进行身份验证
- `/logout` - 退出当前会话
- `/mcp` - 管理 MCP 服务器连接
- `/model` - 在可用的聊天模型之间切换
- `/resume` - 恢复之前的聊天会话
- `/whoami` - 检查您当前登录的用户

<Info>使用 `/help` 查看所有可用命令。</Info>

## 开发工作流

<Info>
  **推荐方法**：在 TUI 模式中开始复杂任务，以迭代和
  完善您的方法。一旦您有了可靠的工作流，就可以将其转换为 无头模式进行自动化。
</Info>

### 工作流模式

1. **🔬 在 TUI 模式中实验**

   - 在人工监督下尝试复杂的开发任务
   - 迭代提示词和方法，直到它们可靠工作
   - 测试边缘情况并完善代理的行为

2. **⚡ 使用持续 AI 自动化**
   - 将经过验证的 REPL 工作流转换为单个命令
   - 部署到 CI/CD、git 钩子或计划任务中
   - 充满信心地运行，因为方法已经过测试
