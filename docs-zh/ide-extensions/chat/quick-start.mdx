聊天功能让您无需离开 IDE 即可轻松向 AI 寻求帮助。获得解释、生成代码并通过对话方式迭代解决方案。

## 如何使用聊天 - 基本用法

### 如何开始对话

在聊天输入框中输入您的问题或请求，然后按 Enter。

**示例：**

- "解释这个函数"
- "我如何处理这段代码中的错误？"
- "为这个组件生成一个测试"

### 如何包含代码上下文

在编辑器中选择代码，然后使用键盘快捷键将其包含在您的聊天中：

- VS Code
- JetBrains

按 `Cmd/Ctrl + L` 将选定的代码发送到聊天

按 `Cmd/Ctrl + J` 将选定的代码发送到聊天

### 如何使用 @ 获取更多上下文

输入 `@` 以包含特定上下文：

- `@Files` - 引用特定文件
- `@Terminal` - 包含终端输出

## 如何处理响应

当 AI 在其响应中提供代码时，您会看到操作按钮：

- **应用到当前文件** - 替换您选择的代码
- **插入到光标位置** - 在您的光标位置添加代码
- **复制** - 将代码复制到剪贴板

## 聊天的专业提示

### 开始新会话

在空聊天中按 `Cmd/Ctrl + L`（VS Code）或 `Cmd/Ctrl + J`（JetBrains）开始新会话。

### 具体明确

包含以下详细信息：

- 您想要实现的目标
- 任何约束或要求
- 您首选的编码风格或模式

### 迭代改进

如果第一个响应不够完美：

- 提出后续问题
- 请求修改
- 提供更多上下文

## 聊天的常见用例

### 代码解释

选择令人困惑的代码并询问 "这段代码是做什么的？"

### 错误修复

包含错误消息并询问 "我如何修复这个错误？"

### 代码生成

描述您想要的内容："创建一个显示用户资料的 React 组件"

### 重构

选择代码并询问 "我如何使这更高效？"
