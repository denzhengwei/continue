## 聊天核心功能如何工作

当您开始聊天对话时，Continue 会：

1. **收集上下文**：使用任何选定的代码部分和 @ 提及的上下文
2. **构建提示**：将您的输入与相关上下文结合
3. **发送到模型**：向配置的 AI 模型请求响应
4. **流式传输响应**：将 AI 响应实时返回到侧边栏

## 上下文管理如何工作

### 自动包含哪些上下文

- 编辑器中选定的代码
- 相关时的当前文件上下文
- 会话中的之前对话历史

### 如何添加手动上下文

- `@Files` - 引用特定文件

## 响应处理如何工作

AI 响应中的每个代码部分都包含操作按钮：

- **应用到当前文件** - 替换选定的代码
- **插入到光标位置** - 在光标位置添加代码
- **复制** - 将代码复制到剪贴板

## 会话管理如何工作

- 使用 `Cmd/Ctrl + L`（VS Code）或 `Cmd/Ctrl + J`（JetBrains）开始新会话
- 清除所有之前的上下文，重新开始
- 有助于在不同任务之间切换
