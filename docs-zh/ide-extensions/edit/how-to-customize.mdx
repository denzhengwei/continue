## 如何设置活动的编辑/应用模型

您可以配置特定模型用于编辑和应用请求。

1. 点击主输入框上方的 3 个点
2. 点击立方体图标展开 "模型" 部分
3. 使用下拉菜单选择用于编辑和应用的模型

![Edit model selection](/images/edit-model.png)

了解更多关于 [编辑角色](/customize/model-roles/edit) 和 [应用角色](/customize/model-roles/apply)。
