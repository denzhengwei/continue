## 编辑功能如何工作

当您开始编辑会话时，Continue 会：

1. **收集上下文**：使用高亮显示的代码和当前文件内容
2. **提示模型**：将收集到的上下文和您的输入指令发送给模型
3. **应用更改**：模型响应随后直接流式传输回您代码中高亮显示的范围，我们应用差异格式来显示建议的更改。

如果您接受差异，我们会删除之前高亮显示的行；如果您拒绝差异，我们会删除建议的更改。

<Info>
**正在寻找能够预测您下一次编辑的 AI？** 查看 [Next Edit](/ide-extensions/autocomplete/next-edit)，这是一个实验性功能，在您开始输入之前主动建议代码更改，超越传统的自动补全，预测整个代码修改。
</Info>

如果您想查看编辑过程中发送给模型的确切提示，您可以 [在提示日志中找到它](/troubleshooting#check-the-logs)。
