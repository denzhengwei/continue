## 如何使用

Plan 模式提供了一个安全的环境，用于理解和构建计划，而不进行更改。它为聊天模型配备了只读工具，允许您在执行修改之前进行探索、分析和规划。

### 使用 Plan

您可以在聊天输入框下方的模式选择器中切换到 `Plan`。

![如何选择计划模式](/images/plan-mode-selector.png)

<Info>
  如果 Plan 显示 "Not Supported" 消息而被禁用，这意味着所选模型或提供商不支持工具。有关更多信息，请参阅 [模型设置](/ide-extensions/agent/model-setup)。
</Info>

### 与 Plan 聊天

Plan 模式与 [聊天模式](/ide-extensions/chat/how-it-works) 和 [代理模式](/ide-extensions/agent/how-it-works) 位于同一界面中，因此使用相同的 [输入](/ide-extensions/chat/quick-start#how-to-start-a-conversation) 发送消息，您仍然可以使用相同的手动方法提供上下文，例如 [`@` 上下文提供程序](/ide-extensions/chat/quick-start#how-to-use--for-additional-context) 或添加 [来自编辑器的高亮代码](/ide-extensions/chat/quick-start#how-to-include-code-context)。

#### Plan 的不同之处

与代理模式不同，Plan 模式：

- 仅使用只读工具（文件读取、搜索、分析）
- 无法修改、创建或删除文件
- 专注于理解和规划，而不是执行
- 提供安全的探索环境

### 常见用例

Plan 模式非常适合：

- **代码探索**：了解代码库的工作原理
- **规划重构**：在进行更改前分析影响
- **调试**：在不修改代码的情况下调查问题
- **架构审查**：了解系统设计和依赖关系
- **预实现规划**：在执行前思考更改

### 示例工作流

1. **从 Plan 模式开始**，探索和理解任务
2. **在模型的帮助下制定计划**
3. **准备好实现更改时切换到代理模式**

例如，您可以说：

> 帮助我理解身份验证系统的工作原理，并计划添加 OAuth 支持的改进

Plan 模式将分析现有代码，理解当前实现，并帮助您创建详细计划——所有这些都不会进行任何更改。

## 切换到执行

当您准备好实施计划时，只需使用模式选择器或键盘快捷键 (`Cmd/Ctrl + .`) 切换到代理模式。对话上下文会保留，因此代理模式可以立即开始实施您制定的计划。

<Tip>
  使用键盘快捷键 `Cmd/Ctrl + .` 在代理、聊天和 Plan 模式之间快速切换。
</Tip>
