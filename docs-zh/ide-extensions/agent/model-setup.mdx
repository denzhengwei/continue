## 系统消息工具如何工作

Continue 实现了一种创新方法，称为 **系统消息工具**，可确保所有模型的工具功能一致，无论其原生能力如何。这使代理模式能够与更广泛的模型和提供商无缝协作。

### 系统消息工具的功能

Continue 不只是依赖原生工具调用 API（不同提供商之间有所不同），而是将工具转换为 XML 格式并将其包含在系统消息中。模型在其响应中生成结构化 XML 格式的工具调用，然后 Continue 解析并执行这些调用。这种方法提供了：

- **通用兼容性** - 任何能够遵循指令的模型都可以使用工具，而不仅仅是那些具有原生工具支持的模型
- **一致的行为** - 工具调用在 OpenAI、Anthropic、本地模型等之间的工作方式完全相同
- **更好的可靠性** - 与原生工具配合不佳的模型通常在使用系统消息工具时表现更好
- **无缝切换** - 在不同提供商之间切换，无需修改您的工作流

### 如何配置代理模式

代理模式会根据模型的能力自动确定是使用原生工具还是系统消息工具。无需额外配置 - 只需选择您的模型，Continue 会处理其余部分。
