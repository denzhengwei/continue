## 什么是计划模式？

计划模式是一个受限环境，提供对代码库的只读访问。它设计用于安全探索、理解代码和规划更改，而不进行任何修改。

![计划模式实际应用](/images/plan-mode.gif)

### 计划模式的主要功能是什么？

- **只读工具**：访问文件、搜索和分析，无风险
- **安全探索**：非常适合理解不熟悉的代码库
- **规划焦点**：在执行前制定实现策略
- **MCP 支持**：与所有 MCP 工具以及内置只读工具一起工作

### 计划模式如何工作？

计划模式过滤可用工具，只包括只读操作。这意味着您可以：

- 读取项目中的任何文件
- 使用 grep 和 glob 模式搜索代码
- 查看仓库结构和差异
- 获取网页内容以获取更多上下文
- 使用所有 MCP 工具

但您不能：

- 创建、编辑或删除文件
- 运行终端命令
- 进行任何系统更改

### 如何开始使用计划模式？

从聊天输入下方的模式选择器中选择 "Plan"，或使用 `Cmd/Ctrl + .` 在模式之间循环切换。

![计划模式选择器](/images/plan-mode-selector.png)

有关工具和使用的详细信息，请参阅 [代理文档](/ide-extensions/agent/how-it-works)，该文档涵盖了代理模式和计划模式。

### 计划模式的常见工作流是什么？

1. **从计划模式开始**，探索和理解
2. **在模型的帮助下制定方法**
3. **准备好实现时切换到代理模式**

<Tip>
  计划模式与聊天和代理模式共享相同的界面和上下文功能。您可以像在其他模式中一样使用 `@` 上下文提供程序和高亮代码。
</Tip>
