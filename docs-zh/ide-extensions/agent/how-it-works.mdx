## 工具握手如何工作

工具为模型提供了一种灵活、强大的方式来与外部世界交互。它们以 JSON 对象的形式提供给模型，包含名称和参数 schema。例如，带有 `filepath` 参数的 `read_file` 工具将使模型能够请求特定文件的内容。

以下握手过程描述了代理模式如何使用工具：

1. 在代理模式下，可用工具与 `user` 聊天请求一起发送
2. 模型可以选择在其响应中包含工具调用
3. 用户授予权限。如果该工具的策略设置为 `Automatic`，则跳过此步骤
4. Continue 使用内置功能或提供该特定工具的 MCP 服务器调用工具
5. Continue 将结果发送回模型
6. 模型响应，可能包含另一个工具调用，然后从步骤 2 开始再次执行

<Info>
  工具可用性因模式而异：- **聊天模式**：不包含任何工具 - **计划模式**：仅包含只读工具 - **代理模式**：包含所有工具
</Info>

## 有哪些内置工具可用

Continue 包含几个内置工具，这些工具为模型提供了对 IDE 功能的访问。

### 计划模式下可用的工具（只读）

在计划模式下，只有这些只读工具可用：

- **读取文件** (`read_file`)
- **读取当前打开的文件** (`read_currently_open_file`)
- **列出目录** (`ls`)
- **Glob 搜索** (`glob_search`)
- **Grep 搜索** (`grep_search`)
- **获取 URL 内容** (`fetch_url_content`)
- **搜索网页** (`search_web`)
- **查看差异** (`view_diff`)
- **查看仓库地图** (`view_repo_map`)
- **查看子目录** (`view_subdirectory`)
- **代码库工具** (`codebase_tool`)

### 代理模式下可用的工具（所有工具）

在代理模式下，所有工具都可用，包括上述只读工具以及：

- **创建新文件** (`create_new_file`)：在项目内创建新文件
- **编辑文件** (`edit_existing_file`)：修改现有文件
- **运行终端命令** (`run_terminal_command`)：从工作区根目录运行命令
- **创建规则块** (`create_rule_block`)：在 `.continue/rules` 中创建新的规则块
- 所有其他用于修改代码库的写入/执行工具
