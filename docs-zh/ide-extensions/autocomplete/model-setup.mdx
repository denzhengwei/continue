## Next Edit 模型

对于预测您下一次编辑的主动代码预测，Continue 支持专门的 [Next Edit](/ide-extensions/autocomplete/next-edit) 模型：

**支持的 Next Edit 模型：**

- `mercury-coder-nextedit`：针对下一次编辑预测优化的主要模型

当您为自动补全配置了兼容模型并具有适当的访问权限时，Next Edit 会自动激活。
