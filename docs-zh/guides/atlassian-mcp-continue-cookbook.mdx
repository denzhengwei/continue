  一个 Atlassian 工作流助手，使用 Continue 和 Atlassian Rovo MCP 实现： -
  跨项目搜索和总结 Jira 问题 - 查找和消化 Confluence 文档 -
  使用自然语言创建和更新 Jira 问题 - 查询 Compass 组件和服务依赖关系 - 使用无头
  CLI 运行自动化 Atlassian 工作流

## 前提条件

开始之前，请确保您有：

- 具有 **Hub 访问权限**的 Continue 账户
  - 阅读：[理解配置 — 如何开始使用 Hub 配置](/guides/understanding-configs#how-to-get-started-with-hub-configs)
- 本地安装的 Node.js 18+
- 带有 Jira、Confluence 和/或 Compass 的 Atlassian Cloud 站点
- 对您要集成的 Atlassian 产品的访问权限

<Note>
  Atlassian Rovo MCP 服务器目前处于 **Beta**
  阶段。核心功能可用，但部分功能仍在开发中。
</Note>

对于所有选项，首先执行：

<Steps>
<Step title="安装 Continue CLI">
  ```bash
  npm i -g @continuedev/cli
  ```
  </Step>

<Step title="理解 OAuth 流程">
  Atlassian MCP 使用 **OAuth 2.1** 进行身份验证。首次连接时，您将完成基于浏览器的授权流程，该流程尊重您现有的 Atlassian 权限。
  </Step>
</Steps>

<Warning>
  要在无头模式下使用代理，您需要 [Continue API
  密钥](https://hub.continue.dev/settings/api-keys)。 所有数据访问都尊重您现有的
  Jira、Confluence 和 Compass 用户权限。
</Warning>

  Atlassian
  MCP。您不必使用这些代理，但它们旨在立即为您提供最佳体验。根据您的需求选择代理，或创建自己的自定义代理。
</Card>

| **Confluence 代理** | 文档管理 | 搜索页面、总结文档、创建/更新页面、管理空间      | [查看代理](https://hub.continue.dev/continuedev/atlassian-continuous-ai-confluence-agent) |

<Tabs>
  <Tab title="📋 Jira 代理（推荐用于问题管理）">
    <Steps>
      <Step title="使用 Jira 代理">
        访问 Continue Mission Control 上的 [Atlassian Continuous AI - Jira 代理](https://hub.continue.dev/continuedev/atlassian-continuous-ai-jira-agent)。此代理针对以下功能进行了优化：
        - 搜索和过滤 Jira 问题
        - 创建和更新问题
        - 冲刺规划和工作量分析
        - 问题转换和状态更新

        无需安装 - 您可以立即从命令行开始使用！
      </Step>

      <Step title="完成 OAuth 授权">
        首次使用时，系统会提示您在浏览器中授权 MCP 服务器。这是一次性设置，根据您的 Atlassian 权限授予访问权限。
      </Step>

      <Step title="运行您的第一个命令">
        在终端的任何位置：
        ```bash
        cn --agent continuedev/atlassian-continuous-ai-jira-agent "Show me my open issues assigned to me"
        ```
        代理将连接到您的 Atlassian 站点并返回结果。
      </Step>
    </Steps>

      ```bash
      alias jira-ai='cn --agent continuedev/atlassian-continuous-ai-jira-agent'
      ```
      然后使用：`jira-ai "your prompt"`
    </Info>

  </Tab>

      </Step>

  <Tab title="🛠️ 手动设置">
    <Steps>
      <Step title="在 Continue Mission Control 上创建新代理">
        转到 [Continue Mission Control](https://hub.continue.dev) 并 [创建新代理](https://hub.continue.dev/new?type=agent)。
      </Step>

      <Step title="添加 Atlassian MCP">
        从 Hub 安装（推荐）或手动添加 YAML。最小 YAML 示例：

        ```yaml title="config.yaml"
        mcpServers:
          - name: Atlassian Rovo MCP
            type: sse
            url: https://mcp.atlassian.com/v1/sse
            connectionTimeout: 30
        ```

        注意：
        - Atlassian MCP 使用 **服务器发送事件（SSE）** 传输类型
        - OAuth 在首次连接时自动处理
        - 配置中不需要 API 密钥或令牌
      </Step>

      <Step title="测试连接">
        启动 Continue 并询问：
        ```
        List my Jira projects
        ```
        如果是第一次使用，系统会提示您在浏览器中授权。
      </Step>
    </Steps>

## Jira 工作流

<Note>
  **使用 Jira 代理**：以下所有示例均使用 [Jira
  代理](https://hub.continue.dev/continuedev/atlassian-continuous-ai-jira-agent)，该代理针对问题管理进行了优化。
</Note>

使用自然语言探索、分类和管理 Jira 问题。代理在后台调用 Atlassian MCP 工具。

<Info>
  **在无头模式下运行**：在提示前添加 `-p` 标志，并在末尾添加 `--auto` 标志：
  ```bash cn --agent continuedev/atlassian-continuous-ai-jira-agent -p "your
  prompt" --auto ``` **重要**：在使用无头模式之前，先完成浏览器 OAuth 身份验证。
</Info>

### 搜索和发现

<AccordionGroup>
  <Accordion title="查找开放的错误" icon="bug">
    搜索跨项目的错误。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "Find all open bugs in Project Alpha"
    ```

  </Accordion>

  <Accordion title="分配给我的问题" icon="user">
    获取分配给您的问题列表。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "Show me all issues assigned to me that are in progress"
    ```

  </Accordion>

  <Accordion title="冲刺规划" icon="calendar">
    分析冲刺工作量和优先级。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "List all issues in the current sprint. Group by assignee and priority. Summarize the workload distribution and flag any overloaded team members."
    ```

  </Accordion>
</AccordionGroup>

### 创建和更新

<AccordionGroup>
  <Accordion title="从描述创建故事" icon="plus">
    将自然语言转换为 Jira 故事。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "Create a story titled 'Redesign onboarding flow' in Project Alpha. Description: We need to simplify the user registration process by reducing steps from 5 to 3. Target completion: Q3."
    ```

  </Accordion>

  <Accordion title="批量创建问题" icon="list">
    从会议记录或规范创建多个问题。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "Create five Jira issues from these meeting notes: 1) Fix login timeout bug 2) Update API documentation 3) Implement dark mode toggle 4) Review security audit findings 5) Optimize database queries"
    ```

  </Accordion>

  <Accordion title="更新问题状态" icon="arrows-rotate">
    使用自然语言转换问题。

    ```bash
    cn --agent continuedev/atlassian-continuous-ai-jira-agent "Move PROJ-123 to In Progress and add a comment: Starting work on this today. ETA: end of week."
    ```

  </Accordion>
</AccordionGroup>

## 故障排除

<AccordionGroup>
  <Accordion title="OAuth 授权问题">
    - **"您的站点管理员必须授权此应用"**：站点管理员需要先完成 OAuth 流程，然后其他用户才能连接
    - **无法完成浏览器授权**：确保您已登录正确的 Atlassian Cloud 站点并拥有必要的权限
    - **连接超时**：增加 MCP 配置中的 `connectionTimeout` 或检查您的网络连接
  </Accordion>

<Accordion title="权限错误">
  - **"访问被拒绝"或"禁止"**：MCP 尊重您现有的 Atlassian
  权限。验证您对要访问的项目/空间/组件有访问权限 -
  **无法创建问题**：确保您在目标 Jira 项目中有"创建问题"权限 - **无法编辑
  Confluence 页面**：验证您在目标 Confluence 空间中有编辑权限
</Accordion>

<Accordion title="速率限制">
  - **标准计划**：中等使用阈值 - **高级/企业计划**：更高的配额（每小时 1,000
  个请求加上每用户限制） - 如果遇到速率限制，请降低查询频率或批量操作
</Accordion>

  <Accordion title="Beta 限制">
    - 批量操作可能受到速率限制的约束
    - 自定义 Jira 字段可能需要显式设置才能被识别
    - 单个会话内不支持工作区/站点切换
    - 查看 [Atlassian Community](https://community.atlassian.com/) 了解已知问题
  </Accordion>
</AccordionGroup>

### 管理员考虑事项

<Card title="针对 Atlassian 站点管理员" icon="shield">
  **安装**：Atlassian Rovo MCP 在首次 OAuth 授权时自动安装（JIT 安装）- 无需 Marketplace 安装。

**管理访问权限**：

- 在 [Admin Hub](https://admin.atlassian.com) 中查看已连接的应用
- 用户可以从其 [个人资料设置](https://id.atlassian.com/manage-profile/apps) 撤销访问权限
- 通过 Admin Hub 中的"用户安装的应用"控件阻止用户安装的应用

**安全性**：所有流量都通过 HTTPS（TLS 1.2+）加密，访问权限尊重现有的用户权限。

</Card>
