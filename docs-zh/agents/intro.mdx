## 先尝试代理：60秒挑战

在创建自己的代理之前，让我们先看看一个代理的实际运行！体验 Continue 代理强大功能的最快方式是使用我们的演示仓库。

![代理 Mission Control](/images/hub/assets/images/agent-mission-control.gif)

### 观看代理在 60 秒内创建 Pull Request

<Steps>
  <Step title="🍴 Fork 我们的演示仓库">
    获取一个安全的沙箱进行实验：
    
    **选项 1：GitHub Web 界面**
    访问 [github.com/continuedev/demo-project](https://github.com/continuedev/demo-project) 并点击 **Fork**
    
    **选项 2：GitHub CLI**
    ```bash
    gh repo fork continuedev/demo-project
    ```
  </Step>

<Step title="🎯 访问 Mission Control">
  前往 [hub.continue.dev/agents](https://hub.continue.dev/agents) 并： - **连接
  GitHub** 并在提示时授权 Continue - 这将使代理能够访问您的仓库以创建 PR
</Step>

<Step title="🚀 运行您的第一个代理">
  **将目标设置为您的 forked 演示仓库** 并尝试以下命令之一：
  <Tabs>
    <Tab title="添加新功能">``` 创建一个计算斐波那契数列的新函数。 ```</Tab>

    <Tab title="修复现有错误">``` 修复 api/users.ts 中的 TypeError ```</Tab>

    <Tab title="添加文档">``` 添加带有设置说明的全面 README 文档。 ```</Tab>
  </Tabs>
</Step>

  <Step title="✨ 观看魔法发生">
    **结果：** 在您的演示仓库中打开一个完整的 Pull Request，包含：
    - 完整的实现或修复
    - 适当的提交消息
    - 详细的 PR 描述
    - 准备好进行审查和合并
  </Step>
</Steps>

<Info>
  **为什么使用演示仓库？** - **安全的测试环境** - 不会对您的生产代码造成风险 -
  **预配置的问题** - 常见的错误和功能可供练习 - **即时结果** -
  无需设置复杂性即可看到代理的实际运行 - **通过示例学习** - 研究生成的代码和 PR
  描述
</Info>

<Tip>
  一旦您看到代理如何与演示仓库配合工作，您将确切了解如何为实际项目创建和自定义自己的代理！
</Tip>

## 运行代理的方式

选择适合您工作流的方法：

<Tabs>
  <Tab title="🌐 Mission Control">
    **用于交互式使用的 Web 界面** 完美适用于： - 探索代理功能 - 行动前审查输出 -
    团队协作 - 一次性任务
    访问地址：[hub.continue.dev/agents](https://hub.continue.dev/agents)
  </Tab>

  <Tab title="💻 CLI (TUI 模式)">
    **用于开发的终端界面** ```bash cn --agent
    continuedev/github-project-manager-agent ``` 完美适用于： - 本地开发工作流 -
    测试代理行为 - 交互式调试 - 快速迭代
  </Tab>

  <Tab title="🤖 无头模式">
    **用于 CI/CD 的自动化执行** ```bash cn --agent
    continuedev/snyk-continuous-ai-agent -p "Run security scan" --auto ```
    完美适用于： - 计划工作流 - CI/CD 集成 - Webhook 触发器 - 后台处理
  </Tab>
</Tabs>
